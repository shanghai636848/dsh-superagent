# dsh-superagent — agent playground

本仓库是 dsh-superagent 的试点目标仓库。

This repository is the working target for the **dsh-superagent** agent.

- **How to ask:** open an issue, or comment `@shanghai636848-agent <task>` on an issue.
- **Who may ask:** GitHub users on the agent's allowed list (currently `@shanghai636848`).
- **Who merges:** a human (`@shanghai636848`). The agent does not enable auto-merge.
- **What to expect:** the agent acknowledges once, works in its own session and branch, and answers in the issue with a reviewable result or a pull request.
- **Scope:** small, explicit changes with a verifiable outcome. Design decisions come back as a question.

This repository is a pilot target. Do not put secrets or production credentials in it.
